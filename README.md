## Описание проекта

Разработка настольного приложения с графическим интерфейсом для расчёта
жилищного кредита. Приложение вычисляет аннуитетный платёж по сумме кредита,
годовой процентной ставке и сроку, а также показывает итоговую переплату.
Проект строится по архитектурному паттерну MVC (Model–View–Controller)
с активной моделью: модель самостоятельно уведомляет представление об
изменении своего состояния через механизм слушателей.

### Основной функционал

1. **Главная форма:**
    * кнопка «Ввести данные» для вызова диалогового окна ввода;
    * вывод результатов расчёта: ежемесячный платёж, общая сумма выплат,
      переплата и коэффициент переплаты;
    * сохранение последних введённых значений и их восстановление при
      повторном вызове формы ввода.

2. **Диалоговое окно ввода:**
    * сумма кредита в белорусских рублях;
    * годовая процентная ставка;
    * срок кредита в годах.

3. **Обработка ошибок:**
    * проверка вводимых значений на корректность формата и допустимый
      диапазон с выводом понятного сообщения об ошибке.

### Расчётная модель

Ежемесячный аннуитетный платёж рассчитывается по формуле

```
P = S · i · (1 + i)^n / ((1 + i)^n − 1),
```

где `S` — сумма кредита, `i` — месячная процентная ставка (годовая, делённая
на 12 и на 100), `n` — срок кредита в месяцах.
