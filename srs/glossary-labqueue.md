# Глоссарий проекта LabQueue

Версия 1.0 · 10.11.2026 · Подготовил Рудольф Н. В., гр. 450501

Глоссарий является общим словарём проекта: термины одинаково понимают Заказчик, разработчики и тестировщики. Определения согласованы со спецификацией требований `srs/srs-labqueue.md` (версия 0.4) и описанием дизайна `sdd/sdd-labqueue.md`.

## Предметная область

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| Дисциплина | учебный предмет с заданным числом лабораторных работ (от 1 до 15), которые студенты защищают преподавателю | REQ-FUNC-002 |
| Группа | учебная группа студентов (например, 450501), привязанная к одной или нескольким дисциплинам | REQ-FUNC-002 |
| Лабораторная работа (ЛР) | задание дисциплины с порядковым номером; предмет защиты | REQ-FUNC-007 |
| Защита | устный ответ студента преподавателю по выполненной ЛР; длится заданное число минут | UC-04, UC-09 |
| Слот | интервал времени преподавателя для защит по одной дисциплине: дата, начало, конец, место, длительность одной защиты, группы | REQ-FUNC-003 |
| Вместимость слота | число мест: целая часть от деления длины слота на длительность одной защиты | REQ-FUNC-003 |
| Серия слотов | набор одинаковых слотов, повторяющихся по дням недели до выбранной даты | REQ-FUNC-004 |
| Окно записи | период, когда студент может записаться: от 7 суток до 1 часа до начала слота | REQ-FUNC-007 |
| Запись | бронирование одного места в слоте студентом для защиты одной ЛР | REQ-FUNC-007 |
| Позиция | порядковый номер записи в очереди слота (определяется временем записи) | REQ-FUNC-011 |
| Расчётное время (ETA) | начало слота плюс (позиция − 1) × длительность защиты; во время занятия пересчитывается от момента вызова текущего студента | REQ-FUNC-011 |
| Лист ожидания | упорядоченный по времени постановки (FIFO) список студентов, ожидающих места в заполненном слоте | REQ-FUNC-009 |
| Продвижение | автоматический перевод первого студента из листа ожидания в записанные при освобождении места | REQ-FUNC-010 |
| Заморозка | состояние за 30 минут до начала слота, в котором лист ожидания не продвигается | REQ-FUNC-010 |
| Живая очередь | состояние слота во время занятия: текущий студент, порядок остальных и расчётное время | REQ-FUNC-012 |
| Вызов | момент, когда преподаватель делает студента текущим; фиксируется в `called_at` | REQ-FUNC-012 |
| Вызов вне очереди | вызов студента не по порядку с обязательной причиной, которая попадает в журнал | UC-10 |
| Неявка | отметка «Не явился», которую преподаватель ставит не раньше чем через 5 минут после вызова | REQ-FUNC-020 |
| Аннулирование записи | потеря записи при неявке: запись не возвращается в очередь, студент получает письмо | REQ-FUNC-020 |
| Ведомость | таблица «студенты × ЛР» со статусом последней защиты каждой работы | REQ-FUNC-018 |
| Отчёт о записи | разбивка студентов группы на категории «Не записывались», «Записаны», «В листе ожидания» и «Неявки» с итогами | REQ-FUNC-019 |
| Журнал | неизменяемый список действий над записями и очередью: время, автор, слот, студент, действие, причина | REQ-OBS-001 |

## Статусы записи

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| WAITLISTED | запись в листе ожидания, места нет | рисунок 3.4 отчёта ЛР5 |
| BOOKED | место закреплено, позиция и ETA известны | рисунок 3.4 отчёта ЛР5 |
| IN_QUEUE | слот начат, студент ждёт вызова | рисунок 3.4 отчёта ЛР5 |
| DEFENDING | студент вызван и защищается | рисунок 3.4 отчёта ЛР5 |
| PASSED | ЛР защищена | REQ-FUNC-012 |
| REWORK | отметка «На доработку»; ЛР не закрыта, нужна новая запись | REQ-FUNC-012 |
| NO_SHOW | неявка; запись аннулирована | REQ-FUNC-020 |
| CANCELLED | запись отменена студентом или слот отменён преподавателем | REQ-FUNC-008 |
| EXPIRED | слот начался, а очередь в листе ожидания до студента не дошла | рисунок 3.4 отчёта ЛР5 |

## Состояния слота

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| SCHEDULED | слот создан, запись ещё не открыта (до начала больше 7 суток) | рисунок 3.5 отчёта ЛР5 |
| OPEN | запись открыта | рисунок 3.5 отчёта ЛР5 |
| REGISTRATION_CLOSED | новые записи закрыты (меньше часа до начала), лист ожидания ещё продвигается | рисунок 3.5 отчёта ЛР5 |
| FROZEN | заморожен лист ожидания (меньше 30 минут до начала) | рисунок 3.5 отчёта ЛР5 |
| IN_PROGRESS | слот идёт, преподаватель ведёт живую очередь | рисунок 3.5 отчёта ЛР5 |
| FINISHED | слот завершён | рисунок 3.5 отчёта ЛР5 |

## Роли и участники

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| Студент | пользователь, который записывается на защиты и следит за своей позицией | SRS, раздел 2.4 |
| Преподаватель | пользователь, который публикует слоты, ведёт очередь и получает отчёты | SRS, раздел 2.4 |
| Администратор | сотрудник кафедры, заводящий преподавателей и группы | SRS, раздел 2.4 |
| Планировщик (актёр «Время») | фоновые задачи системы, запускаемые по времени: заморозка листа ожидания, отправка писем | UC-16, UC-17 |
| Почтовый сервер | внешняя система SMTP, которая доставляет письма пользователям | UC-17 |

## Технические термины

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| Блокировка слота | `SELECT … FOR UPDATE` по строке слота в начале транзакции, из-за чего операции одного слота выполняются строго последовательно | ADR-0004 |
| Outbox | таблица исходящих писем; письмо фиксируется в одной транзакции с изменением очереди, а отправляется фоновой задачей | ADR-0005 |
| Опрос (polling) | запрос браузером снимка очереди раз в 10 секунд вместо постоянного соединения | ADR-0003 |
| ETag | идентификатор версии снимка очереди; если очередь не изменилась, сервер отвечает кодом 304 без тела | SDD, представление 006 |
| Снимок очереди | неизменяемый JSON-объект с позициями, текущим студентом и ETA слота | SDD, представление 004 |
| ADR | запись архитектурного решения (Architecture Decision Record) | `adr/labqueue` |
| SDD | описание дизайна ПО (Software Design Description) | `sdd/sdd-labqueue.md` |
| SRS | спецификация требований к ПО (Software Requirements Specification) | `srs/srs-labqueue.md` |
