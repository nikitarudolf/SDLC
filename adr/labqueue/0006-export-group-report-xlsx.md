# Выгружать ведомость защит в .xlsx с помощью Apache POI

## Контекст и постановка задачи

На втором раунде согласования (02.11.2026) Заказчик добавил функцию F18:
ведомость «студенты × ЛР» по группе с выгрузкой в Excel для выставления
зачётов.

## Драйверы решения

* формат, которым пользуются преподаватели
* лицензия (REQ-COMP-002)
* оценка 5 ч на выгрузку

## Рассмотренные варианты

* Apache POI (.xlsx)
* Выгрузка .csv
* Генерация PDF

## Итог решения

Выбранный вариант: «Apache POI (.xlsx)», потому что Заказчику нужна таблица
Excel с цветовыми статусами, а библиотека распространяется по лицензии
Apache 2.0.

### Последствия

* Хорошо, потому что ведомость открывается в Excel без настройки кодировки
* Плохо, потому что дополнительная зависимость ~10 МБ

### Подтверждение

Тест `GroupReportExportTest`: файл открывается, число строк равно числу
студентов группы.

## Плюсы и минусы вариантов

### Apache POI (.xlsx)

* Хорошо, потому что форматирование и несколько листов
* Плохо, потому что объём зависимости

### Выгрузка .csv

* Хорошо, потому что без зависимостей
* Плохо, потому что нет форматирования, проблемы с кодировкой в Excel

### Генерация PDF

* Хорошо, потому что удобно печатать
* Плохо, потому что нельзя редактировать
